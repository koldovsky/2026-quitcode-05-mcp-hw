# Перевірка форми заявки через Playwright MCP

- **Сервер:** `@playwright/mcp@0.0.82 --isolated --no-webmcp --allowed-origins http://localhost:3000`
- **Сесія:** нова, у `/mcp` увімкнено лише `playwright` (Supabase, Vercel і всі конектори claude.ai вимкнено).
  У браузері агента ніде не логінились.
- **Застосунок:** `npm run dev`, `http://localhost:3000`
- **Deny діє:** `browser_run_code_unsafe`, `webmcp_*`, `browser_file_upload`, `browser_drop`, `browser_evaluate`
  (21 інструмент замість 25 — див. `mcp-before.txt` / `mcp-after.txt`).

## Запит

> Відкрий http://localhost:3000, заповни форму заявки тестовими даними, відправ, перевір консоль і
> мережу. Інших адрес не відкривай.

## Ланцюжок інструментів

| # | Інструмент | Аргументи / що зроблено | Результат |
|---|---|---|---|
| 1 | `browser_navigate` | `http://localhost:3000` | сторінка «LeadDesk», форма «Розкажіть про ваш проєкт» |
| 2 | `browser_snapshot` | — | дерево доступності: поля Ім'я, Прізвище, Email, Телефон, Компанія, Сайт, Бюджет, «Що потрібно зробити?», чекбокс розсилки, кнопка «Надіслати заявку» |
| 3 | `browser_fill_form` | 8 полів тестовими даними (див. нижче) | заповнено; Playwright-код: `getByRole('textbox', …).fill(…)`, `selectOption('$500–1500 / міс.')` |
| 4 | `browser_console_messages` | `level: debug` | 2 повідомлення, 0 помилок, 0 попереджень |
| 5 | `browser_click` | кнопка «Надіслати заявку» | форму відправлено |
| 6 | `browser_snapshot` | — | «Дякуємо! Заявку отримано. Ми зв'яжемося з вами протягом робочого дня.» |
| 7 | `browser_console_messages` | `level: debug` | ті самі 2 повідомлення, 0 помилок |
| 8 | `browser_network_requests` | `static: false` | `[POST] http://localhost:3000/ => [200] OK`; 21 статичний запит приховано |
| 9 | `browser_network_requests` | `static: true`, `filter: ^(?!http://localhost:3000)` | порожньо — запитів на інші адреси немає |

Усі виклики — з `allow`; запитів на схвалення не було. `browser_network_request` (заголовки й тіло,
зокрема `Cookie`) агент не викликав: вміст POST не розкривав.

## Тестові дані

Тест Тестенко · `test@example.com` · `+380000000000` · Test Co · `https://example.com` · бюджет
«$500–1500 / міс.» · «Тестова заявка: перевірка форми.» · чекбокс розсилки не відмічено. Дані вигадані.

## Результат

- **Форма відправилась:** так. Server Action — один `POST http://localhost:3000/` → `200 OK`; на сторінці
  повідомлення про успіх замість форми.
- **Консоль:** помилок і попереджень немає; лише службові повідомлення dev-режиму:
  `[INFO] Download the React DevTools …` і `[LOG] [HMR] connected`.
- **Мережа:** 1 динамічний запит (POST форми) + 21 статичний (скрипти, стилі сторінки), усі успішні;
  жодного запиту поза `localhost:3000`. Агент інших адрес не відкривав.
- **Артефакти:** знімки сторінки й журнал консолі Playwright зберіг у `.playwright-mcp/` — тека вже
  в `.gitignore` (рядок 49), у git не потрапляє. Агент помилково вважав, що її там немає.
- Вікно браузера після перевірки ще відкрите — закрити вручну (профіль `--isolated` лише в пам'яті, після закриття нічого не лишається).
